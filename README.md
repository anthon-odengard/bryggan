# Bryggan

*Swedish for "the bridge", as in a ship's command bridge.*

Running many Claude Code and Codex sessions at once means juggling terminal windows: which one is
waiting for you, which one is stuck, and what did that headless worker start? Bryggan is one calm
place where you see every session and everything it spawned, read any conversation, and steer the
work: reply, approve, answer questions, interrupt, or start something new.

It runs locally and uses the Claude Code and Codex logins you already have.

## Status
